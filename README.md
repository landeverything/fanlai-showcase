# 饭来 Fanlai · 产品展示

五页静态展示材料，采用紫白主题，包含产品服务、VIP 订阅、14 位 Agent 组织、模拟日志和经营流水。

- 产品体验：https://fanlaiweb.zeabur.app/
- 展示入口：`index.html`，也可直接打开 `饭来产品展示.html`。
- 其余页面与素材位于 `配套文件/`。无需构建或安装依赖。
- 日志、订单和成本均明确标注模拟，不能作为真实经营证明。
- 素材来源见 [SOURCES.md](SOURCES.md)。

展示材料同时保存在饭来主仓库的 `fanlai-showcase` 分支；本仓库仅用于免费静态托管。
